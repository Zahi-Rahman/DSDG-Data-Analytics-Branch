# Asking Better Analytical Questions

"Explore the dataset and find something interesting" is intimidating with no starting point. First used Week 2, referenced all semester.

## Four moves

**Compare a rate, not a total.** "Which major has the most graduates" is a fact. "Which major has the best outcome relative to its size" is a question — it needs a ratio you build, not a column you read.

**Name a second explanation.** If two columns move together, don't stop at "does A cause B." Ask what else could explain the pattern. A group that can name two plausible explanations for a correlation is doing analysis. A group that just reports the correlation is doing data retrieval.

**Split the data a second way.** Datasets usually come with one built-in grouping. Try a second one you build yourself — a size cutoff, a rate threshold — and check whether the pattern holds inside each group. Patterns that vanish once you split the data are often the real finding.

**Ask who a summary number is reliable for.** A median can be built from 5 data points or 5,000. Check what it's built on before you present it. If the answer is "not much," that's not a reason to hide the finding — it's part of the finding.

## If a group is stuck

Have everyone write down one column they find surprising, without discussing it first. Compare notes. The disagreements are usually where the real question is.
