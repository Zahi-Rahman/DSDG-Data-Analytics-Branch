# DSDG Data Analytics — Curriculum Repo

Materials for the Data Analytics branch. Every branch meeting has a folder: workshop script, slides, and any data or starter files needed. Officers should be able to run a session from the folder alone.

## Why this repo exists

1. **It's the record.** Every dataset, script, and deck lives in one versioned place instead of scattered across Drive folders and group chats.
2. **It's the first rep.** Using git and GitHub to submit work starts week 1, so by the time it matters for an internship or a Consulting branch application, it's already a habit.

## How the semester is organized

Skills get taught in dedicated blocks (SQL, Python, Excel, Tableau), but every project after that block keeps using the skill alongside whatever's new — nothing gets taught once and dropped. Full reasoning in `docs/curriculum-philosophy.md`.

**Month 1 (this repo, so far): Foundations**
| Week | Focus |
|---|---|
| 1 | What Data Analytics & Data Science are, career paths, GitHub quickstart |
| 2 | Excel as a real analytical tool |
| 3 | Tableau — from spreadsheet to dashboard |
| 4 | Mini-project + share-out (first cycle deliverable) |

**Later in the semester:** SQL, Python, applied statistics, and a semester-long capstone, each following the same 3-weeks-build / 1-week-review cadence.

## Repo structure

```
week-0X-topic/
├── README.md        ← workshop script — start here
├── slides/           ← the deck used in-session
├── data/             ← dataset(s) used that week + a data dictionary
├── starter/          ← starter files for members (if any)
└── scripts/          ← code used to source or prep the data
```
