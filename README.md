# DSDG Data Analytics: Curriculum Repo

## How the semester is organized

Skills get taught in dedicated blocks: SQL, Python, Excel, Tableau. Every project after that block keeps using the skill alongside whatever is new. Full reasoning in docs/curriculum-philosophy.md.

| Week | Focus |
|---|---|
| 1 | What Data Analytics and Data Science are, career paths, GitHub quickstart |
| 2 | Excel as a real analytical tool, using National Park Service data |
| 3 | Tableau, from spreadsheet to dashboard, same dataset |
| 4 | Mini project and share out, the first cycle's deliverable |

Later in the semester: SQL and Python, taught together on one continuous real world dataset across 1-2 months, then a capstone. Members choose their own topic for the capstone rather than working from a dataset we hand them.
