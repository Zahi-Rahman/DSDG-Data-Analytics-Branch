# DSDG Data Analytics: Curriculum Repo

Materials for the Data Analytics branch. Every branch meeting has a folder: the workshop script, slides, and any data or starter files needed. Officers should be able to run a session from the folder alone.

## Why this repo exists

It is the record. Every dataset, script, and deck lives in one versioned place instead of scattered across Drive folders and group chats.

It is the first rep. Using git and GitHub to submit work starts in week 1, so by the time it matters for an internship or a Consulting branch application, it is already a habit.

## How the semester is organized

Skills get taught in dedicated blocks: SQL, Python, Excel, Tableau. Every project after that block keeps using the skill alongside whatever is new. Nothing gets taught once and dropped. Full reasoning is in docs/curriculum-philosophy.md.

Month 1, built so far: Foundations.

| Week | Focus |
|---|---|
| 1 | What Data Analytics and Data Science are, career paths, GitHub quickstart |
| 2 | Excel as a real analytical tool, using National Park Service data |
| 3 | Tableau, from spreadsheet to dashboard, same dataset |
| 4 | Mini project and share out, the first cycle's deliverable |

Later in the semester: SQL and Python, taught together on one continuous real world dataset across two months, then a capstone. Members choose their own topic for the capstone rather than working from a dataset we hand them. Full detail lands here as each month gets built.

## Repo structure

Each week folder follows the same shape. A README that is the workshop script, and the place to start. A slides folder with the deck used in session. A data folder with any dataset used that week, plus a data dictionary. A starter folder with starter files for members, when there are any. A scripts folder with any code used to source or prep the data.

## For officers

Read docs/facilitator-guide.md before your first session. It covers pacing, what to do with groups that finish early or fall behind, and how to run the review week format.

## For members

Clone this repo once, then run git pull before each session to get that week's materials. New to git? week-01-fundamentals-and-github/resources/github-quickstart-cheatsheet.md covers everything you need for week one.
