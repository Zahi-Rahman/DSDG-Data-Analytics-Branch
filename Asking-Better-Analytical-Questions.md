# Asking Better Analytical Questions

Some ideas:

- **Rates and Ratios**. "Which category has the most rows" is a fact. "Which category has the best outcome relative to its size" is a question.

- **Alternative Explanations**. If two columns move together, do not stop at "does A cause B." Ask what else could explain the pattern. A group that can name two plausible explanations for a correlation is doing analysis. A group that just reports the correlation is doing data retrieval.

- **Grouping Data**. Datasets usually come with one built in grouping. Try a second one you build yourself, like a size cutoff or check whether the pattern holds inside each group.

- **Statistical Summaries**. These can be great to understand the distribution of certain fields. Be careful though, because a median can be built from 5 data points or 5,000, so be thorough when analyzing anything

- **Data Quality**. Like mentioned above, data quality issues are important to identify early on for downstream analysis (or modeling), and/or can highlight some important information about the data and its sourcing.
