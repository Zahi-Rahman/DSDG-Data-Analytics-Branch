# Week 4: Mini-Project Share-Out & Retrospective

**Format:** Presentations + structured retro · **Length:** ~75 minutes · **Slides:** `slides/week-04-slides.pptx`

No new content this week — this is the payoff for weeks 2–3, and the template for every review week after (weeks 8 and 12).

## What members should have coming in
Each group, working since Week 3:
1. Their own question on `recent-grads.csv` (or close to it).
2. At least one engineered column that didn't exist in the raw data.
3. A short Excel analysis and a Tableau dashboard.
4. A one-line claim — not just a chart.

Full spec: `mini-project-brief.md`. Rubric: `rubric.md`. Send both at the end of Week 3, not the start of Week 4 — groups need the time in between to build.

---

## 1. Share-out (~30 min)
4–5 minutes per group, dashboard on screen, claim stated in the first 30 seconds — don't let it get buried at the end. 1–2 questions per group from the room. Not a competition — say that up front. The point is seeing 5–6 different approaches to the same dataset.

## 2. Retrospective (~20 min)
Whole-branch discussion, not per-group reports. Three prompts, in order:
1. What felt hard this cycle?
2. What's one thing that clicked?
3. What do you want more practice on before SQL?

Officers: write these down. Real input for pacing the SQL block.

## 3. Wrap-up (~10 min)
Month one was about getting comfortable enough with tools to ask a real question and defend it. Month two is SQL — same instinct, a different way into the data, and the single most-requested skill in analyst postings.
