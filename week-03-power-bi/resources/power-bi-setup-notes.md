# Power BI Setup Notes

## The core issue
Power BI **Desktop** — the full version, and the one this workshop is written for — only installs on Windows. There is no native Mac version.

## Options for Mac users, ranked
1. **Partner with a Windows-laptop member for this session.** Simplest, no functionality lost, and pairs well with the workshop being group-based anyway.
2. **Power BI Service** (app.powerbi.com, browser-based, free with a Microsoft/school email). Can still import a CSV and build most visual types, but report-authoring is more limited than Desktop and some features in this script (calculated columns, in particular) are harder to reach.
3. **Windows in a VM or Boot Camp.** Works, but installation overhead makes it a poor fit for a single 75-minute session — only worth it if a member expects to use Power BI heavily beyond this branch.

## For officers
Send a setup message at least 3 days ahead of this session:
- Windows members: install Power BI Desktop before arriving.
- Mac members: reply so you can pre-assign pairs, or plan to use the Service in-browser.

If more than a third of the branch is on Mac, it's worth raising with your Branch Lead whether future dashboard weeks should default to Tableau Public instead — it's cross-platform, free, and teaches transferable dashboard concepts even though the exact interface differs from Power BI.
